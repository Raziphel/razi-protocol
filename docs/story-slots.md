# Story slots

Generated by `lua tools/story_slots.lua --write`. Do not edit by hand.

Each row is one place in the game where story text goes. The text is written in the
`.cfg` file and section named in the first column, as `key=text` with the key from the
second column. A slot without text shows a stub in writer mode. The length is an
estimate of how many characters fit without scrolling at 1920x1080, interface scale
100 %. How to write and test: [writing-guide.md](writing-guide.md).

Not covered: the planet and route descriptions and the victory screen text. Those are
set when the game loads or for the whole game, so writer mode cannot show them.
